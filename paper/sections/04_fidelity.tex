\section{Teacher-signal fidelity (E1)}\label{sec:fidelity}

E1 asks, without any training, how faithfully each quantized teacher reproduces the BF16
teacher's per-token reward on the rollouts the student actually produces.

\paragraph{Protocol.} For each cold-started student we sample a fixed pool of 2{,}000 rollouts
from the \nProbe{} probe prompts and store the exact token ids. Every rung scores the same pool
(top-\teacherTopK{} log-probabilities at every response position), so all differences come from
the teacher.

\paragraph{Metrics.} Let $r_t^{(b)}$ be the reward of Eq.~\ref{eq:reward} under rung $b$ on
pool token $t$. Because the student term is shared, $r_t^{(b)}-r_t^{(16)}=\log\piT(y_t)-
\log\piT[16](y_t)$: every difference below is a difference between teachers. Over all response
tokens of the pool we report
\begin{itemize}
  \item the Pearson correlation of $r_t^{(b)}$ with $r_t^{(16)}$;
  \item the mean absolute reward error $\mathbb{E}_t|r_t^{(b)}-r_t^{(16)}|$;
  \item the top-\teacherTopK{} KL, $\mathbb{E}_t\,\mathrm{KL}(\tilde p_{16}\,\|\,\tilde p_b)$
        on $K_t$, the BF16 teacher's top-\teacherTopK{} tokens, with both renormalized on $K_t$.
        A rung reports only its own top-\teacherTopK{}, so a token of $K_t$ missing from it is
        assigned the rung's \teacherTopK{}th log-probability (an upper bound on its true value);
        we report the share of such imputed entries;
  \item top-1 agreement, the share of positions where both teachers rank the same token first;
  \item the sign-flip rate, the share of tokens where $r_t^{(b)}$ and $r_t^{(16)}$ have opposite
        signs, i.e.\ where the quantized teacher pushes the student the other way;
  \item the informativeness measure of \citet{understandingopd2026}
        \todo{definition needed from the paper; not implemented until then}.
\end{itemize}
Each metric is repeated within student-entropy buckets with fixed edges
\entropyBuckets{} nats, the same for every student and rung, so
that H3 can be read off directly. Unit tests confirm that identical teachers give perfect scores
and that every metric degrades monotonically as noise is added to the teacher's log-probabilities.
